# Hennie's Photos - Supabase Backend

Node.js + Express backend for Hennie's Photos using Supabase (PostgreSQL + Storage).

## Features

✅ PostgreSQL database (Supabase)
✅ File storage (Supabase Storage)
✅ REST API with Express.js
✅ CORS enabled
✅ Free tier friendly
✅ Easy to deploy (Vercel, Railway, Render)

## Quick Start

1. Read [SETUP.md](./SETUP.md) for complete setup instructions
2. Get your Supabase API keys
3. Deploy with your preferred platform
4. Update your HTML with the API URL

## Architecture

```
Hennie's Photos (Frontend)
        ↓
   Express API
        ↓
    Supabase
    ↙      ↘
PostgreSQL  Storage
```

## Tech Stack

- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: Supabase (PostgreSQL)
- **Storage**: Supabase Storage (S3-compatible)
- **Deployment**: Vercel / Railway / Render (your choice)
